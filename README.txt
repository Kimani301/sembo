HOW TO UPDATE ON GITHUB
1. Unzip this folder.
2. In your GitHub repository upload ALL the files and the "icons" folder (Add file > Upload files), replacing the old ones:
   index.html (website page), app.html (the Osembo app), sw.js, manifest.webmanifest, icons/
3. Wait 1-2 minutes. Your GitHub link now opens the website page with the Install buttons.
4. Open the link in Chrome (Android) or Chrome/Edge (Windows) and tap Install.
