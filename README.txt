OSEMBO UPDATE - how to upload

1. Open your repository on GitHub (signed in as the owner, Kimani301).
2. Click Add file > Upload files.
3. Unzip this folder on your computer, then drag EVERYTHING inside it into GitHub:
   index.html, app.html, manifest.webmanifest, sw.js and the icons folder.
   (They replace the old files with the same names.)
4. Click Commit changes. Wait 1-2 minutes for GitHub Pages to update.
5. On each device: close the installed Osembo app and open it again (twice if needed).

If the install button says it is already installed, remove the old Osembo app from
that device first (Windows: Settings > Apps; Android: long-press the icon > Uninstall),
then open your GitHub link and tap Install again.
