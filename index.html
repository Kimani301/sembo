Install on Windows

Works on a laptop or computer with Microsoft Edge or Google Chrome.

✅ Installed. Open Osembo from your Start menu or desktop.

If the button does not work

  1. Open this page in Microsoft Edge or Google Chrome.
  2. Click the install icon at the right end of the address bar (a small screen with a down arrow), or open the ⋯ menu and choose Apps → Install this site as an app (Edge) or Cast, save and share → Install page as app (Chrome).
  3. Click Install. Osembo opens in its own window and is added to your Start menu.
  4. Optional: right-click the Osembo icon on the taskbar and choose Pin to taskbar.

Install on Android

Works on any Android phone or tablet with Google Chrome.

✅ Installed. Find Osembo on your home screen or app list.

If the button does not work

  1. Open this page in Google Chrome (not inside WhatsApp or Facebook; tap ⋮ → Open in Chrome if needed).
  2. Tap the ⋮ menu at the top right.
  3. Tap Install app (or Add to Home screen), then tap Install.
  4. Open Osembo from your home screen like any other app.

iPhone: open this page in Safari, tap the Share button, then Add to Home Screen.
