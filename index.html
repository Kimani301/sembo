Questions

Does it work without internet?

Yes. After the first visit the app opens offline. Changes sync when you are back online.

I do not see the Install button.

Use Chrome or Edge on Windows and Android, or Safari on iPhone. If the app is already installed, the button is hidden.

How do I get updates?

Open the app while online. It updates itself and shows the newest version the next time you open it.
